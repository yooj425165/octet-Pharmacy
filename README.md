# 옥텟 약국

고등학교 과학 수업용 시간 관리 게임의 첫 번째 프로토타입입니다. 원자의 전자 배치와 이온결합·공유결합을 처방 놀이로 배웁니다.

## 실행

`index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다. 별도의 설치나 빌드가 필요 없습니다. 인터넷이 없어도 게임은 작동하고, 온라인일 때만 Google Fonts의 고운 글꼴을 불러옵니다.

## 게임 방법

### 화면별 버튼 배치

- 메인 메뉴는 높이에 맞춰 제목과 여백을 조정하고 버튼 4개를 2열로 표시합니다. 낮은 화면에서는 장식과 부가 문구를 생략합니다.
- 데스크톱·태블릿은 왼쪽에 처방전, 오른쪽에 2열 선택 버튼과 개수 선택·처방 완료·일시정지를 배치합니다.
- 세로 휴대폰은 위쪽에 처방전, 아래쪽에 조작 패널을 표시합니다. 개수 선택과 처방 완료를 나란히 배치해 높이를 줄입니다.
- 높이 500px 이하의 가로 화면에서는 처방전과 조제실을 나란히 표시하고 현황과 전체화면 버튼을 한 줄에 모읍니다.
- 게임은 브라우저의 실제 표시 높이(`100dvh`)에 맞춥니다. 버튼 공간을 먼저 확보하며, 작은 화면이나 글자 확대 시 긴 처방전·해설·오답 목록만 내부에서 스크롤합니다. 터치 버튼은 최소 44px 높이를 확보하고 안전 영역을 반영합니다.
- 조작 공간 확보를 위해 게임 중 원자 캐릭터와 대사 영역은 숨기며 처방전의 환자 정보와 과제는 유지합니다.
- `mobile.css`, `tablet.css`는 기기별 스타일을 담당하며 마지막에 로드되는 `viewport.css`에서 모든 기기의 화면 높이와 조작 영역 배치를 통합 관리합니다.

게임 시작 시 브라우저 전체화면을 요청하며, Esc로 해제하면 진행 중인 처방을 일시정지합니다. 브라우저가 전체화면을 지원하지 않거나 허용하지 않는 경우에도 화면 전체를 채우는 레이아웃으로 동작합니다. 상단의 전체화면 버튼으로 다시 진입할 수 있습니다.

손님은 고장 난 표정과 떨림 효과로 등장합니다. 정답이면 웃는 얼굴, 오답·시간 초과이면 더 격해진 얼굴로 퇴장합니다. 퇴장 연출 후 다음 손님이 자동으로 입장합니다. 대사는 개인적인 이야기만 담고 전자 수나 정답 힌트를 주지 않습니다. 처방 버튼은 화면 하단에 있으며 오답 해설은 영업 종료 후 모아서 확인합니다.

1. 약국 배경의 메인 화면에서 **게임 시작**을 누릅니다. **순위표**에서 이 브라우저의 상위 10개 완료 기록을 볼 수 있습니다.
2. 손님이 제출한 처방전에서 원자핵 전하, 보유 전자 수, 현재 순전하, 전자 배치와 목표를 확인합니다. 모든 시작 손님은 중성 원자이므로 원자핵 전하와 전자 수가 같고 순전하는 0입니다.
3. 일반 손님은 전자 **잃기 / 얻기**와 **1~3개**를 선택합니다. 특별 손님은 함께 결합할 원자를 선택합니다.
4. 선택한 약과 개수가 표시되는 **처방** 버튼을 눌러 제출합니다.
5. 처방 결과와 퇴장 후 다음 손님이 자동 입장합니다. 영업 종료 시 오답마다 손님 정보, 내 처방, 올바른 처방, 과학적 이유를 보여줍니다. 시간 초과는 미제출로 구분하고 당시 선택도 기록합니다.

단축키: A/S/D는 첫째·둘째·셋째 선택, F는 넷째 선택, 숫자키는 개수만 선택, Enter 제출, P 일시정지. 최근 오답은 브라우저 저장소에 저장되며 메인 화면의 **지난 오답 노트**에서 다시 볼 수 있습니다. 새 게임에서 첫 오답이 생기면 지난 기록을 새 영업 기록으로 교체합니다.

- 원소 손님: 원자번호 1~20번(수소~칼슘) 전체.
- 이온결합: 헤어진 나트륨에게 염소를 소개합니다. 전자가 이동해 Na⁺와 Cl⁻가 되고, 정전기적 인력이 작용합니다.
- 공유결합: 화난 산소에게 수소 원자 2개를 소개해 H₂O를 만듭니다.
- 순서: 일반 → 이온결합 → 공유결합 → 일반 → 일반 → 일반을 반복합니다. 원소 손님은 20종을 섞어 모두 등장시킨 후 다시 섞습니다.
- 시간: 첫 손님 22초, 손님마다 0.75초 감소, 최소 6초.
- 오답과 시간 초과는 신뢰도를 각각 1 줄입니다. 신뢰도 3을 모두 소모하면 퇴장 후 자동으로 영업 결과와 오답 노트가 열립니다.
- 점수: 정답 100점 + 남은 시간 비율에 따른 0~50점 + 연속 성공 보너스 최대 100점.
- 일시정지를 지원하며 다른 탭으로 이동하면 자동으로 일시정지됩니다. 돌아와서 **계속하기**를 누르세요.
- 카운터 안쪽에서 손님을 바라보는 1인칭 화면입니다. 원소 손님이 한 명씩 입장하며, 입장 연출이 끝나면 처방 시간이 시작됩니다. 동작 줄이기 설정에서는 입장 애니메이션을 생략합니다.
- 영업 종료 후 다시 시작하거나 메인 화면으로 돌아갈 수 있습니다. 순위표에는 완료한 영업만 기록됩니다.
- 최고 점수는 브라우저 저장소 사용이 가능할 때 저장됩니다.

## 과학적 모형의 범위

옥텟 규칙은 많은 주족 원자의 결합을 설명하는 경향이며 모든 원자에 적용되지는 않습니다. 수소는 전자 2개로 안정해지는 듀엣 규칙을 따릅니다. 게임의 전자 처방은 전자 수 변화만을 단순화하며, 실제 반응에는 상대 물질과 에너지 조건이 필요합니다. NaCl은 독립된 분자가 아닌 이온 결정입니다. 물의 공유결합은 전자 이동이 아닌 전자쌍 공유로 설명합니다. 연애·감정·약은 의인화이고 물이 되어 시원해진다는 설정도 비유입니다. 실제 물 생성 반응은 발열 반응입니다.

## 파일과 수정 지점

- `index.html`: 한국어 화면, 과학 노트.
- `style.css`: 약국 테마, 원자 그림, 모바일 레이아웃.
- `pharmacy.svg`: 약장, 출입문, 카운터를 그린 로컬 약국 배경.
- `game.js`: 손님 데이터, 처방 판정, 타이머, 점수와 게임 진행.
- `README.md`: 실행법과 발표용 규칙 설명.

새 일반 손님은 `game.js`의 `electronCases`에 추가합니다. 제한 시간은 `nextCustomer()`의 `state.duration`에서 수정합니다. 디자인 색상은 `style.css`의 `:root`에서 변경합니다.

## 수업 발표 포인트

사용자 입력 → 처방 조건 비교 → 점수·신뢰도 변경 → 다음 손님이라는 흐름으로 설명할 수 있습니다. 배열과 객체는 손님 정보에, 조건문은 정답 판정에, 이벤트는 버튼 조작에, `requestAnimationFrame`과 `performance.now()`는 남은 시간 계산에 사용합니다.

## 확장된 원소와 조작

- 시작 전 5초간 작은 키 안내 모달이 표시됩니다. 다른 탭에서는 카운트가 멈춥니다.
- A/S/D/F는 물리 키 코드로 처리하므로 한글 입력 상태에서도 작동합니다. 숫자키와 숫자패드는 전자 개수 또는 같은 결합 원자의 개수만 선택하며, 다른 약이나 원소 종류를 선택하지 않습니다.
- 입장 후 손에 든 처방전을 약사에게 전달합니다. 전달 애니메이션 완료 후에만 타이머를 시작합니다. 동작 줄이기 설정에서도 전달 완료 순서를 유지합니다.
- He/Ne/Ar은 처방 불필요를 판단합니다. H는 H₂, B는 BF₃, C는 CH₄, Si는 SiH₄의 공유결합 문제입니다. BF₃는 붕소 주위 전자 6개로 옥텟 예외입니다. Li/Be 이온은 듀엣을 만족합니다. 다른 전자 처방은 단순화된 이온 전자 수 모형이며, 모든 실제 결합을 이온결합으로 단정하지 않습니다.
